# curaprema-site

Site estático da campanha de apoio ao segundo ciclo de panchakarma de Prema Mandir (`curaprema.com`).

Página única, auto-contida (`index.html`, imagens embutidas em base64), servida via `nginx:alpine`.

Deploy: Docker Compose na `vps-ibiete` (`181.215.135.29`), atrás do Traefik, domínio `curaprema.com` / `www.curaprema.com`.
